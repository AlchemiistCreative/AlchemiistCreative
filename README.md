### 🚀 Featured Project - OpenHVX

**[OpenHVX](https://openhvx.org)** is an open-source Infrastructure as a Service (IaaS) control plane built specifically for Microsoft Hyper-V.

The idea behind OpenHVX is simple: make Hyper-V infrastructure easier to provision, manage, and automate through a centralized, multi-tenant platform.

Inspired by platforms like OpenStack, OpenHVX explores a more lightweight approach to infrastructure orchestration, without the complexity of a full cloud stack.

**Key areas:**

- 🏗️ Infrastructure orchestration and VM lifecycle management
- 🔐 Multi-tenancy and role-based access control
- ⚙️ Task scheduling and automated host selection
- 🌐 API-driven infrastructure management
- 📦 Resource inventory and state management
